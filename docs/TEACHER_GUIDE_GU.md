# શ્રી ભડભીડ પ્રાથમિક શાળા - શિક્ષક એડમિન માર્ગદર્શિકા (Teacher CMS Guide)

આ માર્ગદર્શિકા શ્રી ભડભીડ પ્રાથમિક શાળાના આચાર્યશ્રી અને શિક્ષકગણ માટે છે. આ એડમિન પેનલ દ્વારા કોઈપણ ટેકનિકલ કોડિંગ વગર સીધા તમારા મોબાઇલ કે કમ્પ્યુટર પરથી વેબસાઇટમાં નવી માહિતી ઉમેરી શકો છો.

---

## ૧. એડમિન પેનલમાં પ્રવેશ (Login) કેવી રીતે કરવો?

1. બ્રાઉઝરમાં વેબસાઇટ ખોલી છેલ્લે `/admin` લખો (ઉદાહરણ: `https://shree-bhadbhid-primary-school.vercel.app/admin`).
2. સ્ક્રીન પર **"Sign in with GitHub"** અથવા **"Personal Access Token"** નો વિકલ્પ દેખાશે.
3. પ્રથમ વખત લોગિન માટે તમારું GitHub એકાઉન્ટ લિંક કરવું અથવા એડમિનિસ્ટ્રેટર પાસેથી મળેલ ટોકન દાખલ કરવું.
4. લોગિન થતાં જ સરળ ગુજરાતી ભાષામાં તમામ મેનુ દેખાશે.

---

## ૨. નવો બ્લોગ લેખ (New Blog Post) કેવી રીતે મુકવો?

1. ડાબી બાજુના મેનુમાંથી **"શાળા બ્લોગ (Blog Posts)"** પર ક્લિક કરો.
2. ઉપર જમણી બાજુ આપેલ **"New Blog Posts"** (નવો લેખ) બટન દબાવો.
3. નીચેની વિગતો ભરો:
   - **લેખ શીર્ષક (Title):** દા.ત. *વાર્ષિક રમતોત્સવ ૨૦૨૬*
   - **URL સ્લગ (Slug):** દા.ત. *varshik-ramotsav-2026* (અંગ્રેજીમાં નાની લિપિમાં)
   - **તારીખ (Date):** આજના દિવસની તારીખ પસંદ કરો.
   - **મુખ્ય ફોટો (Cover Image):** તમારા મોબાઇલ ગેલેરીમાંથી સારો ફોટો અપલોડ કરો.
   - **ટૂંકો સારાંશ (Summary):** ૨-૩ વાક્યોમાં લેખનો સારાંશ.
   - **લેખની વિગત (Content):** સમગ્ર કાર્યક્રમનો અહેવાલ ગુજરાતીમાં ટાઇપ કરો.
4. ઉપર આપેલ **"Publish" (પ્રકાશિત કરો)** બટન દબાવો.
5. **પરિણામ:** ૩૦ થી ૪૫ સેકન્ડમાં આપમેળે વેબસાઇટ પર નવો બ્લોગ લાઈવ થઈ જશે.

---

## ૩. નોટિસ બોર્ડમાં નવી સૂચના (New Notice) કેવી રીતે ઉમેરવી?

1. મેનુમાંથી **"નોટિસ બોર્ડ (Notices)"** ખોલો.
2. **"Add to નોટિસ યાદી"** પર ક્લિક કરો.
3. વિગતો ભરો:
   - **ગુજરાતી શીર્ષક:** દા.ત. *શૈક્ષણિક પ્રવાસ ૨૦૨૬ ફી અને ફોર્મ બાબત*
   - **કેટેગરી:** પસંદ કરો (પ્રવેશ / પરીક્ષા / સુવિધા / પરિપત્ર)
   - **બેજ:** દા.ત. *મહત્વપૂર્ણ*
   - **વિગતવાર વર્ણન:** વાલીઓ માટે જરૂરી સંપૂર્ણ સૂચના.
4. **"Publish"** દબાવો.

---

## ૪. ફોટો ગેલેરીમાં નવો ફોટો કેવી રીતે મુકવો?

1. મેનુમાંથી **"ફોટો ગેલેરી (Photo Gallery)"** ખોલો.
2. **"Add to ફોટો યાદી"** પર ક્લિક કરો.
3. તમારા મોબાઇલ અથવા કેમેરામાંથી ફોટો સિલેક્ટ કરો.
4. કેટેગરી પસંદ કરો:
   - *કાર્યક્રમો* (તહેવાર/સભા)
   - *રમતગમત* (દોડ/રમતોત્સવ)
   - *વર્ગખંડ* (સ્માર્ટ ક્લાસ/અભ્યાસ)
   - *સુવિધાઓ* (કેમ્પસ/ભોજન)
5. ફોટાનું શીર્ષક લખો (દા.ત. *યોગ દિવસની સામૂહિક ઉજવણી*).
6. **"Publish"** દબાવો.

---

## ૫. નવો યુટ્યુબ વિડીયો (New YouTube Video) કેવી રીતે જોડવો?

1. સૌપ્રથમ શાળાની સત્તાવાર યુટ્યુબ ચેનલ (`@bhadbhidprimaryschool`) પર વિડીયો અપલોડ કરો.
2. વિડીયોની લિંકમાંથી ૧૧ અક્ષરનો **Video ID** શોધો:
   - ઉદાહરણ: જો લિંક `https://www.youtube.com/watch?v=UaWGftcnuNc` હોય, તો Video ID `UaWGftcnuNc` છે.
3. એડમિન પેનલમાં **"યુટ્યુબ વિડીયો"** પર જાઓ.
4. વિડીયો શીર્ષક, Video ID અને ટૂંકી વિગત લખી **"Publish"** કરો.
